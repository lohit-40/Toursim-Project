# Indian Tourism Analytics Dashboard

## Features

* 📈 Statistical Distribution visualization
* 🥧 Composition Analysis (region and monument breakdown)
* 🌌 Multi-Dimensional 3D tourism comparison
* 🧮 Correlation Heatmap for tourism metrics
* Interactive sidebar filters (metric and location)
* KPI summary cards for visitor insights
* Interactive data table for raw dataset exploration

---

## Installation

### Requirements

* Python **3.8+**
* dash **2.0+**
* plotly **5.0+**
* pandas **1.3+**
* openpyxl **3.0+**

### Install dependencies

```bash
pip install dash plotly pandas openpyxl
```

### Run the dashboard

```bash
python app.py
```

Open in browser:

```
http://127.0.0.1:8060
```
